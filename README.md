# The Living Script

App interattiva per esplorare l'alfabeto cirillico: lettere, pronuncia, storia e giochi didattici.

## Stack

- React 19 + TypeScript
- Vite
- Framer Motion
- Tailwind CSS

## Sviluppo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Il progetto si può pubblicare facilmente su:

- **Vercel** (consigliato): connetti il repo GitHub e usa `npm run build` con output `dist`
- **Netlify**: stesso procedimento
- **Cloudflare Pages**: importa il repo e imposta il build command

Base path: `/` (default, nessuna configurazione aggiuntiva per Vercel/Netlify).
